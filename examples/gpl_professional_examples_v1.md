# GPL professional examples v1

## Purpose

This file provides neutral professional GPL examples. The examples avoid fictional universes and are intended for public technical documentation.

## 1. Customer support response

Human request:

```text
Prepare a professional response to a dissatisfied customer.
```

GPL:

```text
INTENTION: "Prepare a professional response to a dissatisfied customer"
EMOTION: valence("calme") intensity(0.65) tint("empathique")
GLYPHE: glyphes(CLIENT, SUPPORT, CONFIANCE, RISQUE)

```
